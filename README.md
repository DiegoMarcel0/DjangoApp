# DjangoApp
Proyecto para hacer una aplicación con Django

Pasos para la ejecución

1. Tener instalado Docker y Docker-compose. Tenerlo corriendo.

2. Ejecutar desde el directorio donde esta el docker-compose.yml
para construir las imagenes del archivo

`docker-compose build` 


3. Ejecutar para levantar los contenedores

`docker-compose up -d`  //-d para ejecutarse en segundo plano y no en la terminal


Nota:Para terminarlo:

`docker-compose down`
